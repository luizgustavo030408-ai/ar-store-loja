# AR Store — Loja (catálogo com compra pelo WhatsApp)

Site estático. Não precisa de build.

## Editar produtos, preços, cores e tamanhos
Abra `assets/produtos.js`. Cada produto tem nome, marca, categoria, preço,
descrição, cores (com as fotos de cada cor), tamanhos e, opcionalmente, modelos.
Fotos ficam em `assets/img/`.

## Publicar
GitHub → Vercel (Add New → Project → Import → Framework: Other → Deploy).

## Próxima etapa
Trocar `assets/produtos.js` por dados vindos do Supabase + painel administrativo.
